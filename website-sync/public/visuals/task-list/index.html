DataLund Task List

Browse and select projects in Power BI. RAG status, progress, and groups in one scannable list that cross-filters your report.

AppSource Help page. Works next to DataLund Gantt chart. For questions, use Support.

Features

  • Scannable project / task rows — click to filter the rest of the report
  • Optional RAG status chips (Red / Amber / Green, flexible text)
  • Progress bar and percent when Progress is bound
  • Group / phase section headers
  • Density presets shared with DataLund Gantt (Compact / Comfortable / Large)
  • Tooltips for milestones, obstacles, and notes
  • No network calls — runs in the Power BI sandbox

Fields

  • Project (required)
  • Optional: RAG, Group, Project lead, Progress, Start Date, End Date / Duration, Tooltips

Suite

  • Gantt — when tasks run
  • Task List — what’s in the portfolio right now
